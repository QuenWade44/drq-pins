# data/

Once a month, add files to this folder. On GitHub, click **Add file**, then **Upload files**. The weekly run reads them and uses them to make better pins.

Use these file names:
- `pinterest_YYYY-MM.csv`: your Pinterest Analytics export (top pins, outbound clicks)
- `tpt_YYYY-MM.csv`: your TPT sales or product stats export

If there are no files here, the weekly run uses the seasonal plan in system/STRATEGY.md.
